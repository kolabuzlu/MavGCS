# Video window. DirectShow is the only way to see virtual
# cameras on Windows; Qt's own camera support cannot.
# pygrabber names the devices, OpenCV reads the frames. macOS needs no
# equivalent: it names devices with system_profiler, which is part of the
# system, and captures through OpenCV's AVFoundation backend.
#
# pygrabber is marked Windows-only because its comtypes dependency does
# "from ctypes import HRESULT, OleDLL, WinDLL" at module scope. Both ship
# as pure-Python py3-none-any wheels, so pip installs them anywhere
# happily and the failure only appears at import. list_devices() now
# chooses its enumerator by platform and so never reaches that import off
# Windows, but the marker stays: a dependency should say where it
# belongs, and a dead DirectShow stack has no business on a Mac.
#
# The version is pinned on macOS and deliberately not on Windows, which
# is the only place in this file the two platforms differ.
#
# The macOS wheels stopped carrying FFmpeg after 4.12: 4.14 and 5.0 both
# report "FFMPEG: NO", and an rtsp:// URL is refused in 0.0s with
# "backend is not available (plugin is missing...)" - so network cameras
# do not work at all, and the failure is indistinguishable from a
# mistyped address. The Windows wheels still ship
# opencv_videoio_ffmpeg500_64.dll (30MB of it), so Windows is unaffected
# and stays on the current release.
#
# 4.12.0.88 is the newest macOS wheel that answers "FFMPEG: YES", checked
# one version at a time: 4.10, 4.11 and 4.12 carry libavcodec and
# libavformat, 4.14 and 5.0 carry neither. Local USB and capture-card
# cameras work on any version - AVFoundation is built in everywhere - so
# this pin buys the network half of the video window and nothing else.
#
# Worth revisiting: if a later macOS wheel ships FFmpeg again this can go,
# and video_view._has_ffmpeg() will say so in the window rather than
# leaving it to be discovered.
opencv-python-headless; sys_platform != "darwin"
opencv-python-headless<4.13; sys_platform == "darwin"
pygrabber; sys_platform == "win32"
